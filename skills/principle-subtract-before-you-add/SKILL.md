# 先减后加

演进一个系统时，先去掉复杂度，再建造。默认做减法。

把简化当成持续投入。离开时，设计应比你接手时略简单一点、能力略强一点，对外表面相同或更小。

- 先移除，再建造
- 先砍再打磨（先到达最小形态，再投入质量）
- 按观察到的用法设计，而不是按臆测的边界情况
- 不要超出规格要求去臆造校验器、解析器或守卫
- 简化提示词（删掉重复指令和过重的模板）
- 一份参考没有新内容时，删掉它，不要留一个桩
