# 先减后加

演进一个系统时，先去掉复杂度，再动手构建。默认选择做减法。

把简化当成持续投入。让设计在相同或更小的接口面下，比你接手时更简单一点、能力更强一点。

- 先删再建
- 先砍到最小再打磨（先做到最小，再投入质量）
- 按实际观察到的用法设计，不为臆想的边界情况设计
- 不做超出规格要求的推测性校验器、解析器或守卫
- 简化提示词（去掉冗余指令、过度模板）
- 引用没有新内容时，直接删掉，不要留个占位
