# Slack 对话

## 怎么搜

Slack MCP 工具各不相同。先确认有哪些 Slack MCP 可用，并查看它的工具 schema。它可能需要 `mcp_auth`。如果认证失败，就停下来，报告这个缺口。

1. **按作者限定搜索。** 搜 PR 作者在 PR 合并日期前后的消息。这能大幅缩小范围，而且经常能挖到关键信息。
3. **搜 PR URL。** Slack 里经常在评审或讨论 PR 时贴出链接。搜 PR URL（或者只搜 `/pull/<number>`）。
4. **搜错误字符串。** 如果代码处理某个特定错误，就搜这个错误字符串。事故讨论串经常能浮出来。

## 常见坑

- **频道考古有边界。** 太老的消息可能因为保留策略已经没了。如果某个日期之前什么都找不到，记下这个保留断点。
- **没搜到的私信。** 很多决定是在私信里做的，而私信搜不到。你会漏掉它们。这是已知的局限。
- **把玩笑当成“决定”。** Slack 很随意。“哈哈直接干就完了”不是决定，哪怕它出现在提交之前。要找的是经过思考的讨论。
- **单条消息脱离上下文。** 不看讨论串，单条消息读起来常常和上下文里不一样。一定要拉出讨论串。
- **认证失败。** 如果 MCP 没认证，就停下来。不要编造发现。报告 Slack 搜不了。
