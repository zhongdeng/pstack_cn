# Slack 对话

## 如何搜索

Slack 的 MCP 工具各不相同。先看有哪个 Slack MCP 可用，并检查它的工具 schema。它可能需要 `mcp_auth`。如果认证失败，停下来并报告这个缺口。

1. **按作者收窄的搜索。** PR 作者在 PR 合并日期前后的消息。范围会急剧缩小，而且常常能挖到金子。
3. **PR URL 搜索。** Slack 在评审或讨论 PR 时经常贴出链接。搜索 PR URL（或只搜 `/pull/<number>`）。
4. **错误字符串搜索。** 如果代码处理某个特定错误，就搜索那个错误字符串。事故线程常常会浮出来。

## 常见陷阱

- **频道考古的限制。** 很旧的消息可能因为保留策略而消失。如果某个日期之前什么都找不到，记下这条保留悬崖。
- **搜不到的私信。** 很多决定发生在无法搜索的私信里。你会错过它们。这是已知限制。
- **把随口的玩笑当成“决定”。** Slack 很随意。“Lol just do the thing” 不是决定，即使它出现在那次提交之前。要找经过考虑的讨论。
- **单条消息里的上下文坍缩。** 没有线程时，单条消息读起来往往和在上下文里不一样。始终把线程取回来。
- **认证失败。** 如果 MCP 没有认证，就停。不要编造发现。报告 Slack 无法搜索。
