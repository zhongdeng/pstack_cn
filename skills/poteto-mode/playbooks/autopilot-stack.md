### Autopilot-stack

跑 Autopilot-full 手册，但不要合并。

1. **代替第 5 步，停在已验证。** 当每个 PR 都已在它当前的 head 上验证过并且是绿的，就停，然后把这些 PR 交给操作者。交出之后，没有操作者的放行，谁都不要推送。每一次循环节拍的提示都点名这个文件，这样每一次节拍都看得到不合并这条规则。
2. **只有当一个 PR 建立在另一个 PR 之上时，才把它叠上去。** 这是第 3 步的唯一例外。按 `playbooks/opening-a-pr.md` 的 **大小和栈**，把这个 PR 的基设成另一个 PR 的分支，而不是主干。代替第 2 步变基到主干，每个 PR 变基到它的父 PR 的分支，栈根变基到主干。下面那个 PR 上的一个新 head 会把上面的 PR 重新叠好，而一次重新叠栈没有改变其 `git patch-id` 的 PR 保留它的裁决。
