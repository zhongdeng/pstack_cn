### 视觉对齐

**像素级精确的等价由你负责。基线就是规格。你不动它。** 等价由图像 diff 验证，不靠眼睛。

1. 任何迁移之前先建立基线：一套视觉回归装置，对当前组件的各个状态截图，在对齐两种实现时再加上目标。没有基线，就没有对齐声明。这是阻塞性的前提，不是后续。
2. 反捷径条款，说出来并守住：不改装置，不篡改基线，不为了让 diff 通过而重组组件。如果基线看起来是错的，停下来问，不要编辑它。
3. 一次迁移一个组件。跨工作树并行，每个组件一个负责人（**separate-before-serializing-shared-state** 原则技能）。共享原语作为阻塞阶段先迁移。
4. 经控制技能，在对应的交互面上用图像 diff 对照基线验证每个组件。非零 diff 就是失败。调查像素差值。每个组件用 `/loop`，直到 diff 为零。
5. 按组件或按安全的一批运行 **打开 PR**。

**回复：** 迁移了哪些组件、每一个的 diff 结果、基线装置的位置、还剩什么。
