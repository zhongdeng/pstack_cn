# 基础性思考

写逻辑之前先把数据形状弄对。尽早定下核心类型，把每一种访问路径走一遍，按主要路径来选结构。把结构变干，不是把每一行都变干。

在参与者之间共享状态之前，问另一个参与者同时改它会怎样。答案不是「什么都不会」，就隔离。

先搭脚手架。对后面每一个阶段都有帮助的东西（CI、测试、共享类型）最先做，做之前先删掉死代码。提交保持小，一次只做一件事。
