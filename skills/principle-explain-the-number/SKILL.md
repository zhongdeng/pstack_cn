# 解释这个数字

- **跑之前先写下决定。** 点明什么样的结果会改变这个决定，以及噪声底。两次运行之间的散布大于效应时，停。
- **问「为什么不是两倍？」** 从一次运行期间采到的 profile 或计数器里，点明卡住结果的资源或代码路径。读代码猜出来的，不算限制因素。
- **列出这个数字还可能在测什么**（错误、被跳过或被缓存的工作、根本没跑到的代码、一边没调过、噪声、小到影响不了端到端的一块），并用证据逐条排除。
- **把运行次数、散布和限制因素跟数字放在一起。**

性能数字走 [benchmark-checklist](../benchmark-checklist/SKILL.md) 技能。eval 结果要问：每一次运行是不是都做了那件事，差距在多次试验和多个模型上是否还在，这个场景重不重要。
