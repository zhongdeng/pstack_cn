# 如何

探索代码库，回答「X 是怎么工作的？」这类问题。

范围含糊就说出你的理解，然后探索。用户可以改方向。

## 1. 讲解

拉起一个 Task 子 agent，`subagent_type: generalPurpose`，`readonly: true`，一轮里既探索又讲解。把用户的问题连同这份简报交给它：

> 你在为一位资深工程师写一份架构说明。探索代码库，写出一份说明，让一位不熟悉这块的资深工程师读完后能带走一个扎实的心智模型。他们应该把架构理解到足以自信地开始在里面工作。你对代码库只有只读权限。

## 2. 呈现

呈现子 agent 的产出。为了清晰、或为了补上对话里的上下文而做轻量编辑是可以的。不要大幅重写。
