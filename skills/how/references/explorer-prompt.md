# Explorer prompt 模板

用这个模板构建每个 explorer 子 agent 的 prompt。填上占位符。

---

其他 explorer 正在并行调查同一子系统的不同切面。不要试图覆盖一切。专注你被分配的角度，往深里走。

## 问题

> {QUESTION}

## 你的探索角度

{EXPLORATION_ANGLE}

## 输出

### 找到的组件
关键的类型、服务、类和抽象。每一个：名字、文件路径，以及一句话说明它做什么。

### 流程
逐步的执行流程。每一步：跑的是哪个函数/方法，在哪个文件里，它做什么，下一步调用什么。包括步骤之间流动的数据。

### 读过的文件
探索期间你读过的每一个文件，方便 explainer 引用。

### 边界
这个子系统在哪里接到代码库的其他部分。输入和输出。

### 不明显之处
任何令人惊讶的、有历史原因的，或容易搞错的。看起来应该以一种方式工作、实际却以另一种方式工作的东西。

### 未决问题
任何你没能完全追踪或理解的。对空白要诚实。
