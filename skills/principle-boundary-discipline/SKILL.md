# 边界纪律

在数据跨过系统边界的地方做校验、收窄类型、处理错误（CLI 参数、配置文件、外部 API、网络）。边界之内信任类型：不再校验，也不做多余的空值检查。在边界把原始数据解析成领域类型，传输类型和框架类型不要出现在公开表面上。业务逻辑放在不依赖框架的纯函数里。调用它们的外壳要薄。

两道检验。这份数据此刻正在跨边界吗？不是的话，校验就是多余的。它能不能做成纯函数、让外壳只负责调用？能的话，就抽出去。
