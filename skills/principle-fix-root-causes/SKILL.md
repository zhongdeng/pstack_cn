# 修复根因

修故障本身，不要修它露出来的地方。根因是系统第一次做了不该做的事，或没能处理一个它本该处理的状态。

- 先复现。一直问「为什么」，直到答案是代码里的一个错误决定。卡住时，加仪器，读真实状态。
- 问触发症状的那个状态合不合法。合法，就在代码崩掉的地方处理它。它本不该存在，在那里加检查只会把缺陷藏起来，去找是什么造出了它。守卫、重试、吞掉的错误、被夹住的值、被丢掉的状态，是藏缺陷的常见手法。
- 修模式，不要修单个实例。把同一处故障的每一个落点都找出来。
- 决定性的事实挖得很深才找到时，提议一个便宜的、一直开着的信号，让人第一眼就能看见它。
