# 从第一性原理重新设计

整合变更时，不要把它硬拼到现有设计上。要像这个需求从一开始就是基础假设那样重新设计。

- 读完所有受影响的文件，理解当前设计
- 问自己："如果带着这个新需求从零开始写，我们会怎么建？"
- 把变更传播到每一处引用：类型、文档、示例、理由说明部分
- 先想清楚整个重新设计，再增量交付

这就是把变更整合进现有设计时保住选择权的方法。
